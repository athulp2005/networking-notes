# Network Devices

## Overview

Network devices are hardware components that help connect devices and control the flow of data across a network.

Common network devices include:

- Network Interface Card (NIC)
- Access Point
- Switch
- Router
- Modem
- Server

---

## 1. Network Interface Card (NIC)

A Network Interface Card (NIC) is the hardware that allows a device to connect to a network.

It can provide either:

- Wired network connectivity
- Wireless network connectivity

### Example

A laptop's Ethernet adapter or Wi-Fi adapter acts as a network interface.

---

## 2. Access Point

An Access Point (AP) provides wireless network connectivity to devices.

It allows devices such as laptops and phones to connect to a network using Wi-Fi.

### Example

A Wi-Fi access point allows a laptop to connect wirelessly to a network.

---

## 3. Switch

A switch connects multiple devices within a network.

It forwards data between connected devices.

### Example

In an office network, computers and printers can be connected to the same switch.

---

## 4. Router

A router connects different networks and decides where network traffic should be sent.

It helps forward data between networks.

### Example

A home router connects devices in the home network to the Internet.

---

## 5. Modem

A modem connects a network to an Internet service provider (ISP) and converts signals so that communication can take place over the ISP's connection.
