# Network Cables

## Overview

Network cables are physical transmission media used to connect devices and carry data between them.

Common types of network cables include:

- Twisted Pair Cable
- Coaxial Cable
- Fiber Optic Cable

---

## 1. Twisted Pair Cable

Twisted pair cable consists of pairs of copper wires twisted together to reduce electromagnetic interference.

It is commonly used in Ethernet networks.

### Types

- UTP — Unshielded Twisted Pair
- STP — Shielded Twisted Pair

### UTP

UTP does not have additional shielding around the twisted pairs.

It is commonly used in homes, offices, and LANs.

### STP

STP has additional shielding that helps reduce electromagnetic interference.

It can be useful in environments with high electrical interference.

### Common Categories

Examples include:

- Cat5e
- Cat6
- Cat6a

---

## 2. Coaxial Cable

Coaxial cable uses a central conductor surrounded by insulation and shielding.

It has been widely used for:

- Cable television
- Internet connections
- Older networking systems

---

## 3. Fiber Optic Cable

Fiber optic cable transmits data using light through optical fibers.

It provides high bandwidth and can transmit data over long distances.

### Advantages

- High speed
- Long-distance transmission
- Resistant to electromagnetic interference
- High bandwidth

### Types

- Single-mode fiber
- Multi-mode fiber

---

## Comparison

| Cable Type | Transmission | Main Characteristic |
|---|---|---|
| Twisted Pair | Electrical signals | Common Ethernet cable |
| Coaxial | Electrical signals | Shielded copper cable |
| Fiber Optic | Light | High speed and long distance |

---

## Twisted Pair vs Fiber Optic

### Twisted Pair

- Uses copper wires
- Uses electrical signals
- Generally cheaper
- Common in LANs
- Easier to install

### Fiber Optic

- Uses optical fiber
- Uses light signals
- Supports high bandwidth
- Suitable for long distances
- Not affected by electromagnetic interference

---

## Key Points

- Network cables provide a physical path for data transmission.
- Twisted pair cables are commonly used in Ethernet networks.
- UTP has no additional shielding.
- STP provides additional shielding against interference.
- Coaxial cable uses a central conductor and shielding.
- Fiber optic cable uses light to transmit data.
- Fiber optic is suitable for high-speed and long-distance communication.

## Summary

Network cables are an important part of wired networking. Twisted pair, coaxial, and fiber optic cables use different methods to transmit data and have different characteristics, making each suitable for different networking environments.
